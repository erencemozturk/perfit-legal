# PerFIT — Yasal Metinler

PerFIT mobil uygulamasının Gizlilik Politikası ve Kullanım Koşulları.
Yayınlanan adres: https://erencemozturk.github.io/perfit-legal/

Kaynak `index.html`; uygulamanın kendi deposundaki `docs/legal/index.html`
dosyasının yayına alınmış kopyasıdır.

Play Console'un istediği hesap silme URL'si:
https://erencemozturk.github.io/perfit-legal/delete-account/
Kaynağı `delete-account/index.html`; giriş gerektirmez, uygulama içi
adımları ve uygulamaya erişilemediğinde kullanılacak e-posta yolunu
anlatır.
